# VOSR 手机端：NPU / GPU

安装 `vosr-restore-debug.apk`，再导入所需后端的模型包。模型导入完成后，推理无需电脑或网络。

1. 在“推理后端”选择 NPU 或 GPU。
2. 如果提示导入模型，按下表选择对应设备和后端的 ZIP。旧 512 输出模型需要更换；不同芯片的 NPU 包、两个后端的包不能混用，桌面 1.4B 模型也不能导入。
3. 选择照片，点击“开始复原”。输入等比例调整到最长边 832，按 512×512 输入块、96 输入重叠、416 输入步长处理；固定 2×，每块输出 1024×1024。832×624 共 4 块。拼接后缩回原图尺寸，通过高斯金字塔与原始 LR 融合，支持取消。
4. 处理完成后对比并保存，图片写入相册 `Pictures/VOSR`。

| 设备 | NPU 模型包 | GPU 模型包 |
| --- | --- | --- |
| 小米 13 / SM8550 | `vosr-0.5b-htp-v73-1024-models.zip` | `vosr-0.5b-ncnn-vulkan-1024-models.zip` |
| OPPO PMA110 / SM8850 | `vosr-0.5b-sm8850-htp-v81-1024-models.zip` | `vosr-0.5b-sm8850-ncnn-vulkan-1024-models.zip` |

拍照可直接点“拍照并复原（≥10×）”，在系统相机中设置变焦后拍摄。只有原始 EXIF 的数字变焦记录 ≥10× 才处理；缺失或不足时提示重拍。拍照使用固定 2×，先统一最长边 832、重叠 96 复原，再缩回拍照原尺寸与原始 LR 融合，保存结果仍是原图尺寸。详见 `docs/12-camera-restoration.md`。

NPU 支持小米 13 的 HTP v73 和 PMA110 的 HTP v81；大尺寸 DiT 按组加载，SM8850 启用 far mapping。GPU 为 ncnn Vulkan 兼容路径：小米 13 受 128 MiB 缓冲区限制，VAE 在 CPU 执行；PMA110 可使用 GPU VAE，部分其它算子仍回退 CPU。两个后端使用同一套官方 0.5B 权重。切换后端会释放旧会话，应用被回收后需重新加载。

新 1024 输出规格的 NPU 功能验收中，单块原生调用约 11 秒，包含分组加载；12MP 输入的四块复原及原尺寸融合约 87 秒。GPU 的 CPU VAE 开销较大，建议小米 13 使用 NPU。该样例没有控制温度和休眠状态，详细数据见 `docs/14-input-patch-512.md`。阶段 10 的 1.588 秒 NPU、38.55 秒 GPU 属于旧 512 输出规格。

PMA110 的 12MP 四块 NPU 样例约 43.8 秒，原生调用约 6.9–7.3 秒/块；GPU 完整单块调用约 169 秒。两台手机均建议使用 NPU。本轮没有固定温度和频率，另有一次 NPU 加载明显变慢，记录见 `docs/15-sm8850-adaptation.md`。新手机的系统相机实拍 EXIF 尚未验收。

APK 是 ARM64、Android 10+ 的开发签名验证版，详细 profile 默认关闭。模型和组件许可随本目录提供，生成式复原可能补出原图中无法确认的细节。

## 电脑侧

项目：`E:\work\ai\aaa-ncnn-vosr`。工具、模型和缓存仍集中于 `E:\work\ai`，不参与手机实际复原。

```powershell
.\scripts\setup-mobile.ps1
.\scripts\build-android.ps1
.\scripts\install-android.ps1 -Backend both
# 仅更新 APK，保留手机已有模型
.\scripts\install-android.ps1 -SkipModels
# 文件和日志验收，不截屏
.\.venv\Scripts\python.exe scripts\test-photo-backends.py --deploy
```

安装脚本使用 `--no-streaming`，按设备 SoC 选择已验证模型；同时连接多台手机时提供 `-Serial <设备序列号>`。首次准备 Python 转换环境和官方权重可运行 `scripts/setup-mobile.ps1 -WithConversion`；必要时提供 `-Proxy http://127.0.0.1:7897`。Android GPU JNI 使用 NDK r30，QNN JNI 使用已有 r28。完整构建还需要已安装的 Flutter、JDK 17、Android SDK 和 QAIRT 2.44，默认位置见 `scripts/env.ps1`；v81 SDK 文件的补齐步骤见阶段 15。

交付文件大小和 SHA-256 见 `SHA256.json`。Git 中只包含源代码、测试、文档和模型清单；APK、大模型和厂商库在本地交付，不嵌入 Git 历史。

手机“下载”目录中此前的无 1024 后缀模型包属于旧规格，新版请使用本目录列出的 1024 输出模型包。
